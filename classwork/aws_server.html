EV Charging Station Locator

Introduction

Assignment for GIS Server and Cloud Class

I developed a full-stack GIS web application that visualizes EV charging stations across Illinois.The project was hosted on an AWS EC2 instance running ArcGIS Server, where I published dynamic feature services to support real-time data display.

System Architecture Diagram

The user interface was built using the ArcGIS API for JavaScript, providing users with an intuitive interface to explore charging station locations, availability, and related metadata. The dynamic feature updates are handled by a Python service script that periodically scrapes data from the Open Charge Map API and directly updates the hosted feature service on the EC2-based ArcGIS Server
